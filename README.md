# 国际智能制造博览会办展项目 · 项目管理实训

> 工程项目管理课程案例：以一个大型行业展会的完整筹办过程为对象，完成 WBS 分解、进度计划、关键路径分析、资源分配与平衡、赶工（工期-成本）优化、里程碑与基准跟踪等项目管理实践，并在 Microsoft Project 中落地为可打开的项目计划文件。

## 一、项目背景

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 国际智能制造博览会办展项目 |
| 项目编号 | PM-2026-104 |
| 主办单位 | 市会展集团有限公司 |
| 承办单位 | 博远国际会展服务有限公司 |
| 支持单位 | 市工业和信息化局 |
| 场馆方 | 国际会展中心 |
| 计划工期 | 162 个工作日（2026-05-11 ～ 2026-12-22） |
| 总预算 | ￥8,600,000 元 |
| 展会规模 | 展览面积 30,000 ㎡，标准展位 1,200 个（含特装） |
| 参展商目标 | 420 家（其中国际展商 80 家） |
| 预计观众 | 专业观众 35,000 人次 |

**项目目标**

- **质量**：参展商满意度 ≥ 90%，现场重大投诉为零，搭建工程一次验收合格率 100%。
- **进度**：在 160 个工作日内完成策划、招展、搭建、办展与收尾，按期开幕。
- **成本**：总投入控制在 860 万元预算内，招展收入覆盖成本并实现盈利。
- **招商**：完成 420 家参展商签约，展位出租率 ≥ 95%，赞助收入 ≥ 120 万元。
- **安全**：展会期间零安全事故、零踩踏事件，消防与安保方案通过审批。

## 五、关键路径与赶工思路

> 以下口径来自案例数据表「赶工方案」工作表中对关键路径的标注；实际关键路径、时差与工期以 Microsoft Project 计算结果为准。

- **关键路径任务（18 项）**：项目启动会 → 展会主题与定位策划 → 总体方案与预算编制 → 方案评审与立项 → 展位规划与价格体系 → 招展宣传推广 → 参展商招募与签约 → 展位分配与确认 → 展馆布局与动线设计 → 特装展位设计搭建 → 公共区域与氛围布置 → 布展与现场验收 → 嘉宾接待与注册 → 现场安保与秩序维护 → 展期服务与应急处理 → 撤展与场地恢复 → 财务结算 → 客户回访与总结。
- **赶工原则**：优先压缩关键路径上成本斜率（元/天）最低的任务；每压缩一天复核关键路径是否发生转移，再继续选择次优组合。
- **成本斜率** =（赶工成本 − 正常成本）÷（正常工期 − 赶工工期），即每压缩 1 天所需增加的成本，明细见 [`exports/crashing.csv`](exports/crashing.csv)。

## 六、如何查看

- **`.mpp` 计划文件**：用 Microsoft Project 打开 `data/` 下的文件，可查看甘特图、网络图、资源使用状况与跟踪基准。
- **在线浏览数据**：直接打开 `exports/` 下的 CSV，无需安装 Project 即可查看任务、资源、赶工与里程碑明细。
- **分析与练习**：见 [`docs/项目分析小结.md`](docs/项目分析小结.md) 与 [`docs/练习指引.md`](docs/练习指引.md)。
