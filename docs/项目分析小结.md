# 项目分析小结

> 本文基于案例数据表（`data/国际智能制造博览会办展项目-案例数据.xlsx`）对范围、进度、资源、赶工与里程碑做客观梳理；涉及关键路径、时差、工期与成本的最终结论，以 Microsoft Project 排程计算为准。

## 1. 范围与 WBS 分解

项目按展会筹办的生命周期划分为 **7 个一级阶段**，每个阶段再分解为若干二级工作包，共 **42 个 WBS 条目**：

| WBS | 阶段 | 负责人 | 主要工作 |
| --- | --- | --- | --- |
| 1.0 | 项目启动与策划 | 张薇 | 立项、主题定位、总体方案与预算 |
| 2.0 | 招商招展 | 招商经理 | 展位规划、宣传推广、参展商签约 |
| 3.0 | 观众组织与宣传 | 市场推广专员 | 观众邀约、媒体宣传、报名系统与物料 |
| 4.0 | 展务筹备 | 展务经理 | 场馆、布局、特装与标摊搭建、展品运输 |
| 5.0 | 同期活动组织 | 活动策划专员 | 开幕式、论坛、交流会、对接会、颁奖 |
| 6.0 | 现场运营 | 现场运营主管 | 布展验收、接待注册、安保、展期服务 |
| 7.0 | 收尾与评估 | 张薇 | 撤展、结算、效果评估、客户回访 |

分解特点：阶段汇总任务工期为 0，明细任务承载实际工期与资源；WBS 编码与任务清单一一对应，便于在 Project 中通过降级 / 升级还原层级结构。

- **依赖关系**：任务间以前置任务编号建立联系，默认为 FS（完成-开始）；存在多前置任务（如「展馆布局与动线设计」前置 10、20；「布展与现场验收」前置 22、23、24、25），可在 Project 中进一步评估 SS / FF 搭接关系对工期的影响。
- **计划工期**：162 个工作日，计划开工 2026-05-11，计划完工 2026-12-22。

## 3. 资源构成

资源库共 **36 项**，分为工时资源与材料资源两类：

- **工时资源（29 项）**：覆盖项目管理、招商、市场、观众组织、设计、展务、搭建、运营、活动、财务、法务、媒体、安保、志愿者等班组；以「最大单位」表示班组人数（如木工 500% = 5 人、安保 800% = 8 人、志愿者 1000% = 10 人），并给出标准费率与加班费率（元/天）。
- **材料资源（7 项）**：展位搭建材料、音响灯光设备、宣传印刷品、展具租赁、纪念品、餐饮服务、绿植花卉，按单价计量。

资源分配以「资源名称」列挂接到对应任务；搭建、安保、接待等多人班组在高峰期容易出现过度分配，需通过资源平衡（Resource Leveling）或调整班次、增加人手解决。

## 4. 赶工（工期-成本）分析

- 赶工表覆盖 **35 项任务**，给出正常工期、赶工工期、最大可压缩天数、正常成本、赶工成本与成本斜率。
- **成本斜率** =（赶工成本 − 正常成本）÷（正常工期 − 赶工工期），单位：元/天，反映每压缩 1 天的边际成本。
- 案例标注为关键路径的任务 **18 项**；赶工优化时应：
  1. 只在关键路径任务上压缩，非关键任务压缩通常不缩短总工期；
  2. 优先选择关键路径上成本斜率最低的任务；
  3. 每压缩一轮重新识别关键路径，防止关键路径转移后原压缩组合失效。
- 斜率较高的任务（如特装展位设计搭建 60,000 元/天、标准展位搭建 36,667 元/天、现场安保 22,500 元/天）压缩代价大，应作为最后选择。

## 5. 可进一步分析的方向

- 在 Project 中核对关键路径与各任务总时差 / 自由时差，与案例标注口径比对。
- 资源平衡后观察工期与成本的变化，比较「延长工期」与「加班 / 增人」两种方案。
- 按练习指引设置基准，录入第 60 个工作日的进度，计算 PV、EV、AC、SV、CV、SPI、CPI。
- 建立风险登记册，对高等级风险制定规避 / 转移 / 减轻 / 接受策略，并预留应急储备（建议为总预算 10%）。
